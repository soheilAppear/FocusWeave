# ChromaBlur — Longitudinal Chromatic Aberration Simulation

## Overview

ChromaBlur is a gaze-contingent rendering mode that simulates the human eye's **longitudinal chromatic aberration (LCA)**. Unlike the monochrome blur mode, which applies a single blur radius based on dioptric defocus, ChromaBlur applies a *different* blur radius to each of the R, G, and B colour channels. This creates visible colour fringing that mirrors the accommodation cue the eye's neural controller uses in natural vision.

The implementation lives in two files:

- `Assets/pseudoVarifocal/GazeDepthAwareFoveatedBlur.shader` — shader keyword `CHROMABLUR_ON`
- `Assets/pseudoVarifocal/GazeDrivenDepthOfFieldPPv2.cs` — `FocusMode.Chromatic`

---

## The Math

### Signed dioptric defocus

For each pixel, the scene depth in metres is read from `_CameraDepthTexture` via Unity's `LinearEyeDepth`. The **signed** defocus in diopters is:

```
D_defocus = (1 / z_pixel) - (1 / z_focus)
```

where `z_pixel` is the linear eye depth of the pixel and `z_focus` is the current focus plane distance. The sign encodes direction:

| Sign | Meaning |
|------|---------|
| `D_defocus > 0` | pixel is **nearer** than the focus plane |
| `D_defocus = 0` | pixel is **at** the focus plane |
| `D_defocus < 0` | pixel is **farther** than the focus plane |

### Thibos reduced chromatic eye model

The Thibos model (Thibos et al. 1992, JOSA A) parameterises the eye's chromatic focal shift as a per-wavelength dioptric offset relative to a green reference wavelength (~550 nm). The default coefficients used here follow:

| Channel | Offset (D) | Physical meaning |
|---------|-----------|-----------------|
| Red     | −0.4 D    | Red focuses *behind* the retina — needing more positive vergence |
| Green   |  0.0 D    | Reference wavelength, no offset |
| Blue    | +1.0 D    | Blue focuses *in front of* the retina |

Per-channel effective defocus:

```
D_R = D_defocus + chromaticOffsetR   // default: D_defocus - 0.4
D_G = D_defocus + chromaticOffsetG   // default: D_defocus + 0.0
D_B = D_defocus + chromaticOffsetB   // default: D_defocus + 1.0
```

### Mip-level mapping

The existing mipped blur render texture (generated by `_blurMipRT.GenerateMips()`) is reused. Each channel is mapped to a mip level:

```
mip_R = clamp( |D_R| × chromaticBlurStrength × fovealScale, 0, maxChromaticMip )
mip_G = clamp( |D_G| × chromaticBlurStrength × fovealScale, 0, maxChromaticMip )
mip_B = clamp( |D_B| × chromaticBlurStrength × fovealScale, 0, maxChromaticMip )
```

The blur RT is then sampled three times at the gaze-centred UV, and the per-channel values are assembled:

```hlsl
output = float4(sampleR.r, sampleG.g, sampleB.b, 1.0)
```

### Foveal scaling

`fovealScale = lerp(chromaticFovealWeight, 1.0, foveaMask)`

`foveaMask` is 0 at the foveal centre and 1 in the periphery. Setting `chromaticFovealWeight < 1` reduces chromatic blur at the gaze centre so foveated acuity is not destroyed. Default value: **0.5**.

## Perceptual consequences

| Pixel depth relative to focus | Dominant colour in high-frequency detail |
|-------------------------------|------------------------------------------|
| At focus plane                | Green sharp, red and blue lightly blurred (fringing) |
| Nearer than focus             | Red is sharpest (D_R smallest); blue most blurred |
| Farther than focus            | Blue is sharpest (D_B smallest); red most blurred |

This sign convention reproduces the retinal image structure the eye's accommodation system uses as an error signal (Cholewiak et al. 2017).

## Default coefficients and tuning

| Inspector field | Default | Notes |
|----------------|---------|-------|
| `chromaticOffsetR` | −0.4 D | Red LCA offset per Thibos model |
| `chromaticOffsetG` |  0.0 D | Green reference |
| `chromaticOffsetB` | +1.0 D | Blue LCA offset per Thibos model |
| `chromaticBlurStrength` | 1.0 | Linear scale from diopters to mip. Increase to exaggerate the effect. |
| `chromaticFovealWeight` | 0.5 | Chromatic blur weight at foveal centre. 0 = no fringing at gaze point. |
| `maxChromaticMip` | 6 | Caps blur magnitude; prevents over-blurring at large defocuses. |

### Tuning `chromaticBlurStrength`

At `1.0` a 1-diopter defocus maps to mip 1, which is roughly equivalent to a 2× downsampled version of the scene. Increasing to `2.0` doubles the blur per diopter, making the cue more salient at the cost of realism. For perceptual experiments targeting accommodation accuracy, values between **0.8 – 1.5** are recommended.

### Tuning `chromaticFovealWeight`

Set to `0.0` to make the foveal centre fully achromatic (traditional foveated blur look). Set to `1.0` to apply full chromatic fringing even at the gaze point (can break apparent sharpness of the fixated target). The default of `0.5` is a perceptual compromise.
